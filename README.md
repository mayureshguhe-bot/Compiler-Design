# Smart Compiler Error Analyzer and Fix Suggestion System

A Python-based desktop application that analyzes Python code, detects selected programming errors, and provides explanations and possible solutions.

## Features

- Simple Tkinter-based GUI
- Detects syntax errors using Python AST
- Detects selected common programming errors
- Provides error description and suggested solution
- Uses SQLite to store error information

## Technologies Used

- Python
- Tkinter
- AST (Abstract Syntax Tree)
- SQLite

## How to Run

1. Install Python 3.x.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python main.py
